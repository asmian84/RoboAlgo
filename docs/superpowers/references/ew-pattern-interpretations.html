Pattern Interpretation Guide — v2 Engine

How the redesigned engine reads each pattern, with internal structure + key rules

Motive Patterns
Impulse — W3 Extended STOCKS / CRYPTO
MOTIVE
5(5-3-5-3-5) · W3 = 1.618-2.618x of W1
  • Rule: W2 < 100% W1 · W3 not shortest · W4 no W1 overlap
  • Guideline: W2 zigzag → W4 flat/triangle (alternation)
  • Key: W5 tends to equal W1 when W3 is extended
  • Key: W3 sub-waves must show valid 5-wave structure
Impulse — W5 Extended COMMODITIES (ZC, CL, GC)
MOTIVE
5(5-3-5-3-5) · W5 extended → 9-wave sequence visible
  • Key: W1 ≈ W3 (equality) when W5 is extended
  • Key: Extended W5 often shows 9 visible sub-waves
  • After: Sharp retrace back to W2 price area
  • Commodity bias: v2 engine checks asset class for W5 ext
Leading Diagonal WAVE 1 or A ONLY
DIAGONAL
5-3-5-3-5 · Converging wedge · W4 overlaps W1
  • Position: ONLY in Wave 1 or Wave A — nowhere else
  • Key: Overlap allowed (unlike impulse Rule 3)
  • Key: Internal structure = 5-3-5-3-5 (not 3-3-3-3-3)
  • After: Strong Wave 3 follows (confirms the diagonal was W1)
Ending Diagonal WAVE 5 or C ONLY
DIAGONAL
3-3-3-3-3 · Converging wedge · Exhaustion signal
  • Position: ONLY in Wave 5 or Wave C — nowhere else
  • Key: Internal structure = 3-3-3-3-3 (all corrective!)
  • Key: W5 may throw over the 1-3 trendline
  • After: Sharp reversal back below diagonal origin
Corrective Patterns
Zigzag (Sharp Correction) WAVE 2 / A / W / Y
CORRECTIVE
A(5) - B(3) - C(5) · B never reaches A origin · C beyond A end
  • Rule: A subdivides into 5 waves (motive structure)
  • Rule: B retraces < 100% of A
  • Rule: C subdivides into 5 waves and exceeds end of A
  • Fib: B = 50-78.6% of A · C = 100% or 161.8% of A
Expanded Flat (Most Common) WAVE 4 / B / 2
CORRECTIVE
A(3) - B(3) - C(5) · B exceeds origin · C exceeds A end
  • Rule: A = 3-wave (corrective) · C = 5-wave (motive)
  • Key: B exceeds the start of A (fakes breakout!)
  • Key: C goes beyond end of A (fakes breakdown!)
  • Trap: Most common flat type — traps traders both ways
Contracting Triangle WAVE 4 / B / X ONLY
CORRECTIVE
3-3-3-3-3 · Converging lines · Thrust = widest part
  • Position: ONLY in Wave 4, Wave B, or Wave X
  • Key: All 5 sub-waves are 3-wave structures
  • Fib: Each wave ≈ 0.618x of the prior wave
  • After: Thrust in trend direction = widest part of triangle
Double Combination (WXY) COMPLEX CORRECTIONS
COMBINATION
W(zz/flat/tri) - X(connector) - Y(zz/flat/tri)
  • Rule: W and Y must be different corrective types
  • Rule: Maximum one triangle in the combination
  • Key: X retraces 38.2-78.6% of W
  • Effect: Sideways drift — time correction more than price
Special Cases the v1 Engine Cannot Handle
Truncated 5th Wave
SPECIAL
W5 fails to exceed W3 end — ONLY after W3 > 2.618x
  • Condition: W3 must be exceptionally strong (> 2.618x W1)
  • Key: v1 engine hard-blocks this (line 524: W5 > W3 required)
  • Signal: Extremely bearish — market exhausted on W3
Running Flat (Trend Strength)
SPECIAL
A(3) - B(3) - C(5) · B > origin · C fails to reach A end
  • Key: B exceeds origin BUT C fails to reach end of A
  • Meaning: Underlying trend is SO strong the correction can't complete
  • v1 engine: Cannot distinguish from expanded flat
  • Signal: Most bullish type of flat — expect powerful continuation
Patterns Within Larger Structures — Where Each Pattern Lives
Zigzag as Wave 2 SHARP CORRECTION
W2 CONTEXT
W2 = 5-3-5 zigzag · Deep (50-78.6% W1) · Sharp/fast
  • Position: Wave 2 in an impulse — classic sharp correction
  • Key: If W2 is zigzag → expect W4 to be sideways (flat/triangle)
  • Trading: Buy the C-wave terminus — W3 launches from here
  • Fibonacci: C end at 61.8% W1 = best long entry level
Flat as Wave 4 — Alternation SIDEWAYS PAUSE
W4 CONTEXT
W4 = 3-3-5 flat · Sideways · Alternates sharp W2
  • Position: Wave 4 only — if W2 was sharp, W4 MUST be sideways
  • Key: Flat lands near prior 4th wave of one lesser degree
  • Trading: Buy C terminus — W5 follows directly upward
  • Fibonacci: W5 from here often = W1 in price (equality)
Triangle as Wave 4 → W5 Thrust APEX = LAUNCH PAD
W4 CONTEXT
W4 = 3-3-3-3-3 triangle · Apex = W5 launch · Thrust = wave a
  • Position: Triangle in W4 only (NEVER W2 alone)
  • Key: Apex is the setup — breakout from e is the entry signal
  • Target: W5 thrust ≈ widest part of triangle (A leg range)
  • Timing: E often creates its own small triangle (micro apex)
Ending Diagonal — Wave 5 Exhaustion REVERSAL SIGNAL
W5 / C ONLY
W5 = 3-3-3-3-3 · W4 overlaps W1 · Wedge converges · Reversal follows
  • Position: Wave 5 or Wave C only — NEVER W1, W3
  • Key: W4 overlaps W1 territory — the ONLY impulse where this is valid
  • All 5 sub-waves are 3-wave (corrective) structures
  • Signal: Reversal is sharp — retrace to at least start of diagonal
Leading Diagonal — Wave 1 Opening NEW TREND START
W1 / A ONLY
W1 = 5-3-5-3-5 · W4 overlaps W1 · Actionary waves are impulsive
  • Position: Wave 1 or Wave A only (opening wave of new trend)
  • Key: Actionary sub-waves (i, iii, v) are 5-wave impulses
  • Signal: Deep W2 retracement follows (62-78%) — don't panic
  • Rare: Mostly seen in bonds/Treasuries — v1 engine never finds this
Double Zigzag (W-X-Y) COMPLEX CORRECTION
COMBINATION
W(5-3-5) – X(connector) – Y(5-3-5) · Both corrections same direction
  • Rule: W and Y both zigzags — deeper combined correction
  • Key: X connector moves opposite direction (38-78% of W)
  • Tell: Second zigzag lower/higher than first = double, not single
  • Trading: Wait for Y's C-wave terminus — then strong resumption
Wave C as 5-Wave Impulse (A-B-C) C-WAVE CONTEXT
C WAVE
A(3) - B(3) - C(5) · C must be 5-wave impulse · Brown's rule
  • Brown's Rule: Every corrective pattern ending at C has 5-wave C
  • Key: C sub-waves confirm the correction is complete (not extending)
  • Target: C = 1.0× A or 1.618× A most common Fibonacci projection
  • After: C terminus = high-probability reversal entry point
Expanded Flat as Wave B — Fake Breakout TRAP PATTERN
B CONTEXT
Outer A-B-C · B = expanded flat · b exceeds A start · c fakes breakout
  • Trap: Inner b-wave falls below outer A start (looks like reversal)
  • Key: Inner c-wave surges above outer A start (looks like breakout)
  • Most common flat type in financial markets (Brown)
  • Signal: Outer C after B is devastating — both bulls and bears trapped
