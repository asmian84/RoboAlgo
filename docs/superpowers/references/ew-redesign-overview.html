New Architecture: Bottom-Up Hierarchical Detection

Instead of brute-forcing pivot combinations, detect small patterns first and compose them upward.

Layer 0
Pivots
Zigzag pivot detection (existing, mostly kept)
➔
Layer 1
Sub-Waves
Identify 3-swing and 5-swing sequences in monowaves
➔
Layer 2
Compose
Build impulse (5-3-5-3-5), zigzag (5-3-5), flat (3-3-5) from sub-waves
➔
Layer 3
Validate
Position rules, alternation, channeling, extensions
➔
Layer 4
Rank
Score by all EW guidelines, maintain 2-3 best counts
