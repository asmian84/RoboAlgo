2 — Design Decisions
Decision 1
Internal Structure Depth
Full recursive sub-pivot detection vs. proportional heuristics (Brown's box method)
Hybrid (Option C)
Full recursion when ≥8 bars inside swing. Proportion heuristics for shorter moves. Mark "indeterminate" honestly when ambiguous.
Risk: many short-bar MonoWaves marked indeterminate on daily data. That's correct, not a failure.
Decision 2
Rewrite Scope
Full rewrite of lines 392–1992 vs. incremental parallel engine
Full Rewrite
Keep: pivots, dataclasses, _validate_impulse_rules, channel code. Delete everything else. No legacy detection logic worth preserving.
Risk: EW detection broken for 2-3 weeks during dev. Acceptable — EW is one engine among many.
Decision 3
Position Validation
Hard gate (triangles reject if not in W4/B) vs. probabilistic scoring
Probabilistic Scoring
Triangle in valid position (W4/B): +20 pts. Triangle in invalid position (W2): −30 pts, never ranked #1. No hard rejections that cascade.
Risk: wrong prior wave ID causes wrong exclusions with hard gates. Scoring handles ambiguity better.
Decision 4
API Contract
Breaking change to multi-count schema vs. backward-compatible wrapper
Backward-Compatible
Old fields direction, current_wave, action stay, now mirror counts[0]. New counts[] array added alongside. Zero frontend changes.
Risk: none. Old API works unchanged. New frontend can use richer counts[].
Decision 5
Performance
Accept 300–1500ms/symbol latency vs. cache MonoWave structures
Cache MonoWaves
Internal structure classification runs once on price load. Cached per-symbol. Scanner re-uses cache across calls. Cuts overhead 80%.
~1-2h extra implementation. Worth it before this hits the scanner at 50+ symbols.

4 — New Architecture: 6 Layers
Layer 0
Pivots
detect_pivots()
detect_macro_pivots()
KEEP existing
›
Layer 1
MonoWaves
Build directional moves between adjacent pivots. Annotate bar count, price change, internal bars.
›
Layer 2 ★ core
Sub-Wave Class.
Hybrid: recursion (≥8 bars) or proportion heuristics (<8 bars). Returns "impulsive" / "corrective" / "indeterminate". Cached per-symbol.
›
Layer 3
Composition
Combine MonoWaves into candidate patterns using internal structure rules. Impulse (5-3-5-3-5), zigzag (5-3-5), flat (3-3-5), triangle (3-3-3-3-3).
›
Layer 4
Validation
3 inviolable rules (hard gate). Position scoring (+/−). Alternation, channeling, Fibonacci, proportionality.
›
Layer 5
Rank
Score by 6 guideline weights. Maintain top-3 counts. Backward-compatible API output with counts[].
★ Layer 2 is the core innovation — the step v1 entirely lacks. Everything else follows from getting this right.

9 — Key Additions From Constance Brown (2012)
CORE PRINCIPLE
"Price swings ≠ Elliott Waves"
The root failure of v1. A price swing is a directional move between two pivot points. A wave requires internal structure. Five swings do not make a five-wave impulse. This is the entire motivation for Layer 2.
BALANCE / PROPORTION
Box method pre-filter
Compare swing proportionality before wave counting. If a correction takes 2.618× the time of the comparable correction, it's a different degree. Visual balance check filters impossible counts early. Implemented as Layer 4 proportionality score.
FIBONACCI CLUSTERS
Multiple projections = high confidence
When multiple Fibonacci projections from different waves land near the same price, that's a strong target zone. If the market ignores these zones, look for a triangle developing — Brown's diagnostic rule. Used in projection generation.
OSCILLATOR RULES
Confirm pattern with momentum
RSI divergence between W3 and W5 confirms W5 ending. RSI bottoms near 40-45 in bull corrections. Composite Index diverging from price with RSI failing = corrective pattern (not new trend). Secondary scoring factor for position assessment.
TRIANGLE RULES (BROWN)
Stricter than most sources
If first leg of apparent triangle is 5 waves → it's a zigzag B-wave. Each wave within a triangle will likely define a different corrective pattern. Wave 'e' often forms its own small triangle. Triangles alone never in W2 — can be B-wave of a correction that is in W2.
EXTENDING SWING COUNTS
5, 9, 13, 17, 21...
Extensions add pairs of swings at front and back. Valid ending counts: 5, 9, 13, 17, 21... An 11-swing sequence never ends an impulse wave. Use the swing count (not sub-labels) as a validity check in composition layer.
