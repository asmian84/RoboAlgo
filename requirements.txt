# top-level `import httpx`, which no declared package installs — starlette only
# pulls it under its `full` extra, and `fastapi` is declared plain. Resolving

# raised ModuleNotFoundError and the entire API failed to start, not one route.

# finnhub, pytz, alpaca — imported lazily inside functions or try blocks, and
